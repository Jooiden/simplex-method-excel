# Математическое моделирование и методы оптимизации в MS Excel

Решение прикладных экономических задач линейного программирования с помощью симплекс-метода и надстройки «Поиск решения» (Solver) в среде MS Excel.

## 📌 О репозитории
В данном репозитории собраны отчеты и электронные таблицы с решениями 8 лабораторных работ по курсу «Математическое моделирование». Каждая работа включает в себя построение математических моделей реальных экономических ситуаций, их формализацию и нахождение оптимальных планов.

---

## 📂 Структура проекта и содержание работ

* **Лабораторная работа №1: Симплекс-метод при решении задач линейного программирования (ЗЛП)**
    * *Суть:* Построение базовых математических моделей, освоение интерфейса электронных таблиц, работа с Мастером функций и графиками.
* **Лабораторная работа №2: Экономические задачи прикладного характера**
    * *Суть:* Оптимизация технологических способов производства, расчет недельного фонда рабочего времени и максимизация прибыли предприятия при ограниченных ресурсах.
* **Лабораторная работа №3: Анализ оптимизационных процессов**
    * *Суть:* Построение сопряженных (двойственных) задач линейного программирования, проведение анализа чувствительности моделей к изменению ресурсов.
* **Лабораторная работа №4: Графический способ решения экономических задач (Часть 1)**
    * *Суть:* Геометрическое представление ЗЛП с двумя переменными, нахождение ОДЗ (области допустимых значений), максимизация дохода на примере расчета структуры выпуска продукции.
* **Лабораторная работа №5: Графический способ решения экономических задач (Часть 2)**
    * *Суть:* Моделирование оптимального состава многокомпонентных смесей (задача о диете/кормах) и графическое решение задачи оптимального состава инвестиций для коммерческого банка.
* **Лабораторная работа №6: Транспортная задача линейного программирования (Базовая модель)**
    * *Суть:* Поиск оптимального распределения поставок однородного груза от 3 баз к 4 пунктам назначения с целью минимизации суммарных транспортных издержек.
* **Лабораторная работа №7: Распределительные транспортные задачи**
    * *Суть:* Моделирование и минимизация расходов учреждения при размещении заказов на комплекты оборудования у различных фирм-поставщиков с учетом ограничений их мощностей.
* **Лабораторная работа №8: Симплекс-метод в задачах минимизации времени**
    * *Суть:* Составление оптимальных схем обработки деталей на различных станках с целью выполнения производственной программы в кратчайшие сроки (минимизация времени).

---

## 🛠️ Используемые инструменты и технологии
* **Среда моделирования:** MS Excel
* **Инструменты анализа:** Интеллектуальный пакет «Поиск решения» (автоматический расчет симплекс-методом)
* **Визуализация:** Построение графиков функций и диаграмм по точкам для геометрического метода

---

## 🚀 Как запустить и посмотреть решения
1. Скачайте нужный файл `.xlsx` из соответствующей папки лабораторной работы.
2. Откройте файл в Microsoft Excel.
3. Чтобы посмотреть параметры оптимизации, перейдите на вкладку **Данные** $\rightarrow$ **Поиск решения**. Там сохранены все целевые ячейки, изменяемые переменные и системы ограничений (неравенств).
